# POLYLAB — Los polímeros | UFPS 2026

Recurso académico interactivo basado en la guía **Los Polímeros: Estructura, Propiedades, Procesamiento y Aplicaciones en la Industria** y el cuestionario original de 20 preguntas.

## Autores
Deiber Santiago Serrano Becerra y Niccol Valentina Ochoa Villamizar. Universidad Francisco de Paula Santander, Ingeniería Industrial, 2026.

## Contenido
- Cinco capítulos completos de la investigación, adaptados para navegación web.
- Laboratorio interactivo para explorar materiales y procesos.
- Calculadora de producción con valores editables.
- Cuestionario autocorregible de 20 preguntas, con revisión de respuestas.

## Abrir localmente
Abrir `index.html` con Chrome, Edge o Live Server en Visual Studio Code. No se requiere instalar dependencias.

## Publicar en GitHub Pages
1. Crear repositorio público en GitHub.
2. Cargar `index.html`, `styles.css`, `script.js` y `README.md` en la raíz.
3. En Settings → Pages seleccionar Deploy from a branch, `main` y `/(root)`.
4. Abrir el enlace publicado por GitHub Pages tras la implementación.

## Créditos
Contenido académico: guía y cuestionario entregados por sus autores. Diseño y desarrollo asistido con IA.
